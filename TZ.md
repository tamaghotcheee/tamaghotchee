## 1. ОБЩИЕ СВЕДЕНИЯ И БИЗНЕС-ЦЕЛИ

### 1.1. Наименование и назначение системы
Программный комплекс **"Poytug GNS"** представляет собой высоконагруженную экосистему для автоматизации процессов:
1. Заказа заправки бытовых и коммерческих баллонов сжиженным нефтяным газом (СУГ / LPG: пропан-бутан).
2. **Модуль Оптовых заказов B2B (от 10 баллонов):** гибкие оптовые цены (скидка до 15%), формирование Электронных счетов-фактур (Е-Фактура / Soliq.uz) и выгрузка документов для Юридических лиц.
3. Покупки новых стальных и композитных взрывобезопасных газовых баллонов и комплектующих.
4. Экспресс-доставки баллонов спец-транспортом (Labo / Isuzu) до двери с точным трекингом в реальном времени.
5. Оповещения об экстренной безопасности и прямой интеграции со службой газа **104**.

### 1.2. Бизнес-показатели (KPI)
* **Среднее время доставки:** ≤ 25 минут (розница), спец-рейс по согласованию (опт от 10 шт).
* **Мультиязычность:** 100% локализация приложения на 3 языках (**UZ** — Узбекский, **RU** — Русский, **EN** — Английский).
* **Конверсия из входа в заказ:** ≥ 75% за счет интуитивного UI и возможности гостевого оформления.
* **Доступность (Uptime):** 99.9% (поддержка от отказоустойчивой микросервисной архитектуры).

## 3. СПЕЦИФИКАЦИЯ 2FA АУТЕНТИФИКАЦИИ И ОПТОВОГО ФУНКЦИОНАЛА

### 3.1. Двухэтапная верификация (2FA: Пароль + SMS OTP)
1. **Регистрация:**
   * **Шаг 1:** Ввод имени / названия организации, номера телефона (`+998...`), надежного пароля (мин. 6 знаков с цветовой шкалой надежности), подтверждения пароля и согласия с правилами.
   * **Шаг 2:** Ввод 4-значного OTP-кода из SMS (таймер 30 сек, авто-фокус по ячейкам, возможность повторной отправки).
2. **Вход в систему:**
   * **Шаг 1:** Номер телефона + Пароль (с кнопкой показать/скрыть 👁️ и валидацией).
   * **Шаг 2:** Ввод SMS-кода для подтверждения входа.
3. **Безопасность и управление сессией:**
   * В профиле и боковом меню отображается статус `2FA Активна (SMS + Пароль) 🛡️`.
   * Кнопка выхода из аккаунта с очисткой токена сессии.

### 3.2. Логика Оптового Заказа (от 10 баллонов):
1. **Автоматическое определение оптового режима:**
   * При выборе количества **от 10 штук** система автоматически переключается в режим **«Оптовый заказ B2B»**.
   * Применяется оптовая скидка:
     * *Баллон 20 КГ:* вместо 75 000 UZS ➔ **65 000 UZS / шт** (-13%).
     * *Баллон 10 КГ:* вместо 45 000 UZS ➔ **38 000 UZS / шт** (-15%).
     * *Баллон 50 КГ:* вместо 180 000 UZS ➔ **155 000 UZS / шт** (-14%).
2. **Формирование документов для юр. лиц:**
   * Появляется дополнительное поле ввода **ИНН Компании / Название организации**.
   * Оплата доступна способами: **Перечислением по Е-фактуре**, **Корпоративной картой (Corporate Uzcard/Humo)** или **Наличными с выдачей накладной**.
3. **Логистика и доставка:**
   * Назначается отдельный грузовой автомобиль (Isuzu / Porter / Labo) с бригадой грузчиков.

## 4. СХЕМА БАЗЫ ДАННЫХ (POSTGRESQL v3.2)

```sql
-- Таблица пользователей с поддержкой 2FA и хэша пароля
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    full_name VARCHAR(150) NOT NULL,
    phone VARCHAR(20) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    two_factor_enabled BOOLEAN DEFAULT TRUE,
    role VARCHAR(20) DEFAULT 'client', -- 'client', 'b2b_client', 'admin'
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Таблица оптовых B2B реквизитов компаний
CREATE TABLE company_details (
    id SERIAL PRIMARY KEY,
    user_id INT REFERENCES users(id) ON DELETE CASCADE,
    company_name VARCHAR(150) NOT NULL,
    inn VARCHAR(20) NOT NULL,
    mfo VARCHAR(10),
    bank_account VARCHAR(30),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Обновленная таблица заказов с оптовыми полями
ALTER TABLE orders ADD COLUMN quantity INT DEFAULT 1;
ALTER TABLE orders ADD COLUMN is_wholesale BOOLEAN DEFAULT FALSE;
ALTER TABLE orders ADD COLUMN company_inn VARCHAR(20);
```

## 5. ВЕРИФИКАЦИЯ И ТЕСТИРОВАНИЕ

1. **Регистрация:** Регистрация требует заполнения имени, телефона, создания и повтора пароля (>= 6 символов) -> переход на шаг 2 с вводом 4 цифр SMS OTP.
2. **Вход:** Вход требует правильного телефона и пароля -> шаг 2 SMS OTP -> успешный переход в приложение с сохранением профиля.
3. **2FA статус:** В личном кабинете отображается активный статус двухфакторной защиты.
4. **B2B Опт:** При увеличении количества баллонов до 10+ штук цена за единицу пересчитывается по оптовому тарифу.
5. **Е-Фактура:** Появляется вариант оплаты «Перечисление (Е-Фактура)» с валидацией 9-значного ИНН.
